# TabHub Messages Editor

双击根目录的 `messages-editor.html`，点「打开」选择本地消息文件。也可以从控制台顶部「Messages 编辑器」打开编辑器。首次启动进入空工作区，每次打开文件都会增加一个文档。合并导入会将消息追加到当前文档；拖入多个文件可分别编辑。Ctrl+S 保存，Ctrl+Shift+S 另存为，Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。

## 工作台交互

编辑器采用三栏工作台：左侧管理消息列表，中间编辑消息内容，右侧查看正文、实际 Hub 主题和格式 Wiki。顶部工具栏管理文件与多文档，底部状态栏提供面板开关和文件状态。桌面端可拖动两条分隔线调整面板宽度；窄屏下检查器与消息列表改为可从状态栏打开的抽屉。

消息卡片同时显示文档内序号、正文首行和摘要。列表中的拖动排序会改变实际导出顺序；搜索仅筛选视图。富文本工具栏提供常用的粗体、斜体、下划线、删除线和文字颜色快捷操作，更多格式仍由统一格式表驱动。搜索框可使用 / 快捷键聚焦。首次打开默认采用深色外观，用户选择的配色会保存在本地。

## 从编辑到显示

1. 在消息列表选择公告。输入搜索词仅筛选列表；勾选消息可批量删除。用「插入」「上移」「下移」或拖拽调整实际导出顺序。数量较多时按页追加列表。
2. 可视化模式以单个文字片段为编辑单位。在片段正文中选择一段文字后应用格式，编辑器会拆分片段并保留已有属性。无选区时格式作用于整段。组合公告可在「消息内容」切换子消息。
3. 源码区支持原生静态数据字面量，包括单引号、注释、未加引号的字段和尾随逗号。可在这里创建或修改队列、条件包及其嵌套关系。「混合」同时显示片段与源码。语法无效时保留输入和上一次有效预览，修正后可导出。
4. 检查器提供正文、实际主题和可搜索的格式 Wiki。锁定模式显示选中的子消息；完整列表模式复用 Hub 的消息池、条件过滤、权重和队列顺序。可调整预览视口、配色、间隔和缩放。切换到 Wiki 或折叠检查器会卸载预览页。
5. 保存后，刷新实际使用该文件的 OBS 浏览器源。编辑器上的播放、暂停及草稿修改只影响预览。

## 文件与恢复

「保存」优先写入通过文件选择器打开的 JS 文件。「另存为」选择新位置，「导出 JS」生成下载。静态 JSON 数组也可作为输入。保存前会对比磁盘原文；遇到外部修改或无法取得写入权限时保留原件并下载副本。拖入文件及部分浏览器的文件选择器只提供读取能力，首次保存时需选择目标。浏览器下载的副本由用户决定是否替换直播文件。

编辑器在 IndexedDB 中保存本地工作区，包括尚未修正的源码；文件状态单独记录。独立编辑器窗口分别保存草稿，点击「本地草稿」可将其他窗口保存的工作区恢复为一组文档。恢复依赖同一浏览器配置和页面地址。打开另一个文档后仍可返回之前的文档继续撤销；刷新后的撤销历史从恢复点重新开始。

## 实现与扩展

| 文件 | 职责 |
| --- | --- |
| `editor/model.js` | 使用随包分发的 Acorn 8.15.0 解析单个静态数组声明，管理稳定行 ID、不可变编辑历史和片段替换 |
| `editor/formats.js` | 为工具栏、Wiki 示例和样式提示提供统一格式表，与 `styles/README.md` 的字段对应 |
| `editor/storage.js` | 本地文件读写、外部修改检查、下载和 IndexedDB 草稿 |
| `editor/app.js` | 多文档、搜索选择、拖拽、组合输入、源码和可视化编辑 |
| `editor/inspector.js` | 主题发现、预览视口、格式 Wiki 和面板偏好 |
| `editor/preview.html`、`editor/preview.js` | 独立 iframe 使用实际 Hub 外框、主题、布局与调度，通过 postMessage 接收父页命令 |

导出使用标准 `const tabHubMessages = [...];` 声明。保留合法数据中的未知字段；注释、引号风格和空白在导出时统一格式化。函数、变量引用、执行语句及动态表达式无法导入。公告文字由共享渲染器写入 DOM 的 textContent。预览页限制资源加载，主题脚本仅来自本地项目中登记的可信主题。

## 验证与分发

- 运行 `node --test tests/messages-editor.cjs` 检查解析、序列化、选区格式、历史及大文件。
- 安装 Python Playwright 与 Chromium 后运行 `python tests/messages-editor-browser.py` 验证离线工作流。环境变量 `CHROMIUM` 可指定浏览器可执行文件。
- 在项目根目录运行 `python tools/package-editor.py TabHub-Messages-Editor.zip`。解压后双击 `messages-editor.html` 即可运行。部署静态 HTTP 时保持同样的相对目录结构。
