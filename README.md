# TabHub

用于 OBS 的透明直播外框。顶部以浏览器标签的形式轮播公告，底部显示直播状态、主题和补充信息。

## 在 OBS 中使用

1. 下载并解压项目。将同一目录的 `console.html` 文件 URL 添加到 OBS「停靠窗口 → 自定义浏览器停靠窗口」，例如 `file:///D:/TabHub/console.html`。
2. 在控制台选择 `main`，展开「管理显示端」，复制「OBS 浏览器源 URL」。在 OBS 中创建浏览器源，取消勾选「本地文件」，粘贴完整 URL。将源置于直播画面上方。1920×1080 显示整个外框，1920×80 可显示顶栏。
3. 第二个场景需要独立控制时，在控制台添加例如 `break` 的 Hub ID，新建一个浏览器源并填入对应 URL。在多个场景引用同一个 OBS 源时，它们共享一个 Hub。
4. 看到显示端在线后，在「广播」选择当前 Hub、指定多个 Hub 或全部在线 Hub，发送公告或控制轮播。回执按显示实例列出。数量上限为零时会拒绝创建标签。实时公告只发送给当时在线的实例。

内置广播使用 `BroadcastChannel`，无需安装服务器。一个安装目录使用一个控制台。控制台与显示页须在同一个 OBS 浏览器环境内，使用相同目录和 URL 形式。普通 Edge/Chrome 中打开的控制台适用于同浏览器测试。若当前 OBS 版本隔离本地文件页面，可将整个目录放到已有的本机静态 HTTP 服务，让停靠窗口和各浏览器源使用同一协议、主机、端口和目录。

控制台中的「当前 Hub 设置」始终只修改选中的 Hub。广播多选适用于发送公告、暂停／启动轮播、清空公告和下一条。暂停／启动会切换每个目标的当前轮播状态，清空会立即移除目标的全部公告标签。可通过 OBS「交互」打开、选中和关闭标签，默认主题也提供暂停按钮。

关闭或隐藏控制台后，广播进入效率模式。显示端只保留事件监听，继续按当前设置轮播。若控制台异常退出，显示端会在最后一次发现消息后约 18 秒进入待机。重新打开控制台会立即发现显示端。轮播仍遵守显示页的可见性和手动暂停状态。

## 外框主题

在控制台选择目标 Hub，打开「界面主题」。可以即时切换默认外框和 Photoshop 外框，默认跟随 OBS 场景。场景名包含 `[dark]` 或 `[light]` 时按首个标记切换（忽略大小写），无标记或无法读取场景时跟随系统。在浏览器源属性中授予读取 OBS 用户信息的页面权限（READ_USER），以便启动时读取当前场景。也可固定浅色、深色或跟随系统。固定配色适合需要跨场景保持一致的直播。主题和配色随 config.js 一起导出。

Photoshop 主题在透明画布上显示文档标签栏和状态信息。通过控制台暂停或恢复轮播。文档标签右侧的加号打开下一条，标题和叉号分别用于选中和关闭。底部缩放比例右侧显示直播状态。在高度不超过 200 px 的浏览器源中，显示紧凑的标签栏与控制按钮。

每个主题位于 `themes/<id>/`，其中 `theme.css` 定义外观和标签测量参数，`motion.css` 定义开合动画、原速时长和缓动。主题使用的图片也放在该目录，并在 `src/settings.js` 的共享主题清单登记。共享布局、设置面板和公告富文本样式位于 `styles/`。添加主题时可沿用现有 DOM 和控制器。

## 设置入口

| 分组 | 用途 |
| --- | --- |
| 公告抽取 | 设置均匀随机、加权随机及时间变量。公告文本保存在根目录的 `messages.js` |
| 消息文字 | 设置轮播及实时公告的字体、字号和左右或居中对齐。字体留空、字号设为 0 时分别沿用主题默认值 |
| 状态栏 | 修改直播状态、本场主题和右侧信息，留空隐藏对应字段 |
| 标签布局 | 数量、最小宽度、按文本长度自适应和固定最大宽度。将数量上限设为 0 可保持空栏 |
| 弹出与关闭 | 选择左右方向、按活动公告字数延长间隔、固定或随机等待及独立关闭间隔。关闭间隔为 0 时停用定时关闭 |
| 动画与滚动 | 标签开合速度与缓动，溢出文字的范围、速度、停留时间和循环方式 |
| 配置迁移 | 导入当前版本的多 Hub 配置 |

默认主题和 Photoshop 主题共用标签宽度规则。「按文本长度自适应」默认开启。空间充足时，每个标签按文字长度和主题内边距展开。空间不足时，从最早打开的标签开始缩，达到最小宽度才继续缩下一个。旧标签都缩到最小后，最近一组按相同百分比缩减文字区域，仍受最小宽度约束。点击历史标签不会改变压缩顺序。关闭自适应后，所有可见标签使用相同的固定宽度，拥挤时等宽缩小。最小宽度默认 62 px。若空间不足以容纳所有标签，会暂时隐藏部分标签。连一个标签也放不下时，标签栏暂时为空。

按活动公告字数轮播时，间隔取保底秒数与活动公告字数乘以每字秒数中的较大值。默认保底 10 秒，每字 0.2 秒。空白不计，标点计入。手动或广播新增标签会重新计时，切换到已有标签只重新计算间隔。

达到数量上限时优先从所选关闭侧移除非活动标签。弹出与关闭同时到期时只进行一次布局更新。暂停轮播只冻结弹出倒计时，自动关闭仍按关闭间隔逐个移除标签。隐藏页面会冻结两个倒计时。

控制台的「广播」「日志」「公告列表」「设置」分页可随时切换。日志按时间记录连接、发送目标、公告内容、执行回执和文件保存结果，最多保留最近 200 条，刷新即清空。

### 公告示例

「公告列表」读取同目录的 `messages.js`，可新增、逐条编辑、排序和删除。普通公告直接编辑文字，富文本、队列和条件包在对应列表行编辑 JSON。点击「保存 messages.js」后覆盖根目录文件，刷新使用该公告库的 Hub 即可载入。

编辑根目录的 `messages.js`，保存后刷新 OBS 浏览器源。使用 `const tabHubMessages = [...];` 声明公告列表。

```js
const tabHubMessages = [
    '欢迎来到直播间',
    '现在是 {{{time:hh}}}:{{{time:mm}}}',
    [{text: '提醒 ', style: {bold: true}}, {text: '报名即将截止'}],
    {type: 'queue', content: ['第一轮即将开始', '请提前准备']},
    {type: 'pack', conditions: [{condition: 'weekday_check', weekday: 6}], content: ['周六特别场']}
];
```

队列按顺序展示。条件包支持 `all_of`、`any_of`、`inverted`、`date_check`、`weekday_check` 和 `random_chance`。

### 保存与导入设置

控制台重开时读取在线 Hub 正在使用的设置。关闭控制台前已应用的设置会保留在仍运行的显示页中。一个 Hub ID 有多个实例时，控制台用最先发现的实例填充设置面板。控制台中的修改与明确导入的设置会下发给该 Hub 的所有在线实例，也会应用到同一控制台会话内重新加载的实例。

点击「保存全部 Hub 配置」，选择项目根目录的 `config.js`。不支持直接写盘时会请求下载，用下载的文件覆盖根目录同名文件。只有手动保存才会生成文件。项目自身不使用 localStorage、IndexedDB、Cookie 或 Service Worker 保存设置和消息。

新版文件包含 `version: 2`、新 Hub 的基础设置 `settings` 和按 ID 索引的 `hubs`。控制台可合入当前版本配置，导入后仍需手动保存。

## 运行链路

1. `src/settings.js` 提供共享配置定义、校验和迁移。`console.html` 的控制台管理表单、内存配置和文件保存，使用 `src/broadcast.js` 与显示端的 `src/hub-receiver.js` 通信。
2. `src/message-source.js` 按当前配置筛选消息池、抽取公告、消费队列，展开时间变量并将文本与样式写入 DOM 节点。该层不持有轮播计时器。
3. `src/app.js` 管理可见性、暂停状态和下一次开关标签的时间。手动和自动弹出共用取消息入口。状态栏文字独立更新。
4. `src/tabs.js` 持有标签与动画状态，处理近期分组、宽度分配、退场和滚动，并向调度器提供活动公告字数。
