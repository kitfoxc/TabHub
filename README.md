# TabHub

用于 OBS 的透明直播外框。顶部以浏览器标签的形式轮播公告，底部显示直播状态、主题和补充信息。

## 在 OBS 中使用

下载并解压仓库，在场景里添加「浏览器」源，勾选「本地文件」并选择 `hub.html`。将源放在直播内容上方，宽高设为画布尺寸。1920×1080 显示整个外框，1920×80 只显示顶栏。所有脚本和样式随项目提供，可离线运行。

右键浏览器源选择「交互」，点击左上角下拉按钮打开设置。叠页按钮暂停或恢复轮播，加号打开下一条公告。点标签标题切换活动标签，点叉号关闭。右侧窗口图标仅用于展示。

## 外框主题

在 OBS 中右键浏览器源，选择「交互」，打开设置 →「界面主题」。可以即时切换默认外框和 Photoshop 外框，或选择浅色、深色、跟随系统。固定配色适合需要跨场景保持一致的直播。主题和配色随 config.js 一起导出。

Photoshop 使用两张 2048×1152 透明外框图，16:9 浏览器源可等比显示，其他比例会铺满源尺寸。点工具栏的主页图标打开设置，画笔图标暂停或恢复轮播。文档标签右侧的加号打开下一条，标题和叉号分别用于选中和关闭。底部缩放比例右侧显示直播状态。在高度不超过 200 px 的浏览器源中，显示紧凑的标签栏与控制按钮。

每个主题位于 `themes/<id>/`，其中 `theme.css` 定义外观和标签测量参数，`motion.css` 定义开合动画、原速时长和缓动。主题使用的图片也放在该目录，并在 `src/theme-manager.js` 的主题清单登记。共享布局、设置面板和公告富文本样式位于 `styles/`。添加主题时可沿用现有 DOM 和控制器。

## 设置入口

| 分组 | 用途 |
| --- | --- |
| 公告抽取 | 设置均匀随机、加权随机及时间变量。公告文本保存在根目录的 `messages.js` |
| 状态栏 | 修改直播状态、本场主题和右侧信息，留空隐藏对应字段 |
| 标签布局 | 数量、宽度、最近几条和更早标签的显示方式。将数量上限设为 0 可保持空栏 |
| 弹出与关闭 | 选择左右方向、阅读完毕后轮播、固定或随机等待及独立关闭间隔。关闭间隔为 0 时停用定时关闭 |
| 动画与滚动 | 标签开合速度与缓动，溢出文字的范围、速度、停留时间和循环方式 |
| 配置迁移 | 导入 TabHub 导出的 config.js 或旧版 tabhub.json |

完整模式按文字宽度展开；压缩模式优先为完整标签让出空间。最小宽度默认 62 px。按打开时间划分最近标签，点击历史标签不会改变分组。达到数量上限时优先从所选关闭侧移除非活动标签。弹出与关闭同时到期时只进行一次布局更新。暂停或隐藏页面会冻结两个倒计时。

### 公告示例

编辑根目录的 `messages.js`，保存后刷新 OBS 浏览器源。使用 `const tabHubMessages = [...];` 声明公告列表。

```js
const tabHubMessages = [
    '欢迎来到直播间',
    '现在是 {{{time:hh}}}:{{{time:mm}}}',
    [{text: '提醒 ', style: {bold: true}}, {text: '报名即将截止'}],
    {type: 'queue', content: ['第一轮即将开始', '请提前准备']},
    {type: 'pack', conditions: [{condition: 'weekday_check', weekday: 6}], content: ['周六特别场']}
];
```

队列按顺序展示。条件包支持 `all_of`、`any_of`、`inverted`、`date_check`、`weekday_check` 和 `random_chance`。

### 保存设置与迁移旧配置

面板里的修改会即时预览，刷新时重新读取项目根目录的 `config.js`。要保存设置，点击「导出 config.js」，用下载的文件覆盖项目根目录中的同名文件，再刷新 OBS 浏览器源。项目通过本地配置文件保存设置。

升级前，可在旧版面板导出 `tabhub.json` 和旧版公告备份。新版可在「配置迁移」中导入旧 JSON，预览后再导出 `config.js`。如果 JSON 内含公告，点击「下载导入的旧版公告」导出 `messages.js`。将它放回根目录并刷新源即可加载。原有浏览器站点数据可在浏览器设置中清除。

## 运行链路

1. `src/settings.js` 集中定义字段、默认值与校验规则，生成设置面板，读写同一份配置。通过校验的修改通知控制器。
2. `src/message-source.js` 按当前配置筛选消息池、抽取公告、消费队列，展开时间变量并将文本与样式写入 DOM 节点。该层不持有轮播计时器。
3. `src/app.js` 管理可见性、暂停状态和下一次开关标签的时间。手动和自动弹出共用取消息入口。状态栏文字独立更新。
4. `src/tabs.js` 持有标签与动画状态，处理近期分组、宽度分配、退场和滚动，并向调度器返回活动公告读完一遍所需的剩余时间。
